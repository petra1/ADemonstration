Überschriften-Struktur

Bei Überschriften gibt es einen Unterschied zwischen nativen und hybriden Anwendungen mit eingebettetem HTML-Inhalt. Während es in HTML sechs Überschriftenebenen (h1 bis h6) gibt, existiert diese Einteilung bei nativen Apps nicht.

Ausgabe von TalkBack

Native Apps

Ihnen ist vielleicht aufgefallen, dass die Überschrift "Alternativtexte" im Gegensatz zur Überschrift "Überschriften-Struktur" von TalkBack lediglich als "Überschrift Alternativtexte" angekündigt wurde. Das liegt daran, dass dieser Text auf einer nicht-visuellen Ebene als Überschrift formatiert ist.

HTML-Inhalt

Bei HTML-Dokumenten gibt TalkBack zum Beispiel "HTML-Inhalt Überschrift 3" aus, da es sich um eine Überschrift der dritten Ebene (h3) handelt. Unabhängig davon, ob ein HTML-Dokument in einem Browser geöffnet oder in eine App integriert wird, kündigt TalkBack die Überschriften immer auf dieselbe Weise an.
