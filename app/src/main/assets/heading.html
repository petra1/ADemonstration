Headings Structure

There is a difference in headings between native apps and hybrids with embedded HTML content. While there are six levels of headings in HTML, from h1 to h6, this is not the case with native apps.

Output of TalkBack

Native Apps

You may have noticed that the heading "Alternative Texts", unlike the heading "Heading Structure", is announced by TalkBack as "Heading Alternative Texts" only. This is text formatted as a heading on a non-visual level.

HTML content

For HTML documents, for example, TalkBack says "HTML content heading 3", since it is a heading of the third heading level (h3). No matter whether an HTML document is opened in a browser or integrated into an app, TalkBack always announces the headings in the same way.
